OpenVPN Install

Installs or removes OpenVPN itself on this app's host machine (systemd service, firewall rules, PKI) -- the Python service-layer preview of openvpn-install.sh's interactive installer. Runs over a scoped SSH connection to the host, not inside this app's own container -- see services/system/host_executor.py. This is a host-level, disruptive action; use it only on a machine you intend to run OpenVPN on.
