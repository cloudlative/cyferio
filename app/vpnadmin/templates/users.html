Device Monitoring (optional)

VPN Device Availability Monitoring -- for a device expected to keep a continuous VPN connection (a branch gateway, an always-on server, a kiosk). If it drops offline for longer than the threshold below, an alert is sent through the channels you enable. Same feature as Manage Monitoring on the Clients page -- enabling it here just skips the extra trip for a device that's meant to be monitored from day one. Leave unchecked to set this up later instead.
